# Solo Adventuring TXT

Base de desarrollo para un RPG de texto con simulación autoritativa en servidor.

## Requisitos

- Node.js 20 o superior.
- npm 10 o superior.

## Instalar

```bash
npm install
```

## Ejecutar el cliente

```bash
npm run dev
```

El cliente queda disponible en `http://localhost:5173`.

## Ejecutar las pruebas

```bash
npm test
```
