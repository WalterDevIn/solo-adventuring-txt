# Documentación

La documentación se divide por responsabilidad:

```text
docs/
├─ README.md
├─ ARCHITECTURE.md
├─ PRODUCT_DECISIONS.md
├─ CHAT_UI_DECISIONS.md
├─ COMBAT_COMPONENTS.md
└─ ai/
   ├─ README.md
   ├─ FRONTEND_WORKFLOW.md
   ├─ FRONTEND_STAGE_1_PLAN.md
   ├─ CURRENT_CONTRACT.md
   └─ contracts/
```

Los documentos ubicados directamente en `docs/` describen el producto, la arquitectura y el dominio. No deben contener instrucciones operativas específicas para chats de IA.

`docs/ai/` contiene exclusivamente el flujo de planificación e implementación asistido por IA, el plan de trabajo, el contrato vigente, los contratos históricos y sus informes.
