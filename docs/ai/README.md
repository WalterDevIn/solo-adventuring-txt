# Documentación operativa para IA

Esta carpeta contiene las reglas de trabajo de los chats que planifican, implementan, revisan y corrigen el frontend.

Archivos principales:

- `FRONTEND_WORKFLOW.md`: reglas operativas.
- `FRONTEND_STAGE_1_PLAN.md`: orden general de la primera etapa.
- `CURRENT_CONTRACT.md`: único puntero al contrato vigente.
- `contracts/`: contratos e informes históricos.

La documentación de producto y arquitectura permanece en `docs/` y es autoridad sobre esta carpeta.
