# Documentación operativa para IA

Esta carpeta contiene el contexto y las reglas mínimas para coordinar los chats de planificación e implementación.

Archivos activos:

- `FRONTEND_WORKFLOW.md`: reglas operativas.
- `FRONTEND_STAGE_1_PLAN.md`: orden general de la primera etapa.
- `CURRENT_CONTEXT.md`: estado operativo breve y único archivo mutable del flujo.

Los contratos nuevos no se guardan en el repositorio. El planificador los entrega como archivos `.txt` descargables y el usuario los adjunta al chat implementador.

`contracts/` conserva únicamente contratos e informes históricos creados antes de este flujo. No debe recorrerse durante el trabajo ordinario.

La documentación de producto y arquitectura permanece en `docs/` y tiene prioridad sobre esta carpeta.
